# 个人AI任务看板项目

## 介绍

个人全栈项目，主要功能有：完整的注册-登录模块。根据用户加载看板，以及根据看板加载看板任务，支持不同用户之间对看板进行编辑。以及使用AI对看板内部数据进行分析

## 技术栈

前端：Html,Css,React,Typescript,vite,ArcoDesign,AntDesign
后端：Node.js
AI：DeepSeek
